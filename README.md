### 👨‍💻 Обо мне:

Уверенный QA-инженер с опытом ручного тестирования веб и мобильных приложений в нагруженных и требовательных к качеству системах. 
Веду весь цикл: от анализа требований и тест-документации до проверки бизнес-логики, UI, интеграций и API. Уверенно работаю с SQL, REST, логами и баг-трекингом. 
Выстраиваю эффективное взаимодействие в команде, менторю, беру задачи под самостоятельное ведение и участвую в релизах. Ориентирован на стабильные релизы и результат на проде.

Базовый опыт автоматизации на Python (PyTest + requests, Selenium): написание автотестов для API и UI, запуск в CI, отчёты Allure.

Ценю системность, автоматизацию и умею находить уязвимости там, где другие их не замечают. Ориентирован на стабильные релизы и реальную пользу для бизнеса.

В свободное время занимаюсь игрой на гитаре🎸 и кроссфитом💪 => вредных привычек НЕТ.
